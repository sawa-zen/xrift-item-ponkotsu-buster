# ポンコツバスター

腕に差し込んで撃つ、ためうちバスターの XRift アイテムです。`Grabbable` の `onUseStart` / `onUseEnd` / `onGrab` / `onRelease`（`@xrift/world-components` 0.64.0 以降）のサンプルを兼ねています。

## 遊び方

1. バスターを掴む（PC は G、スマホは「掴む」ボタン、VR はグリップ）
2. 「使う」を押している間ためる（PC はクリック、スマホは「使う」ボタン、VR は持っている手のトリガー）
3. 離すと撃つ。ためた長さで弾が3段階に大きくなる
   - 0.5 秒未満: 豆粒
   - 1.5 秒未満: ふつう
   - 1.5 秒以上: フルチャージ
   - 溜めの光と音は、押して 0.35 秒経ってから出る（連打で小さい弾を撃つ間は出ない）
4. バスターを持っている人同士で撃ち合える。当たると光がはじけて音が鳴り、HP が減る
   - HP は 5。豆粒で 1、ふつうで 2、フルチャージで 3 減る。残りは筒の上のランプで見える（3 以上は緑、2 は黄、1 は赤く点滅）
   - 0 になると爆発して、1.5 秒後に満タンに戻る（その間は当たらない。勝ち負けは無い）
   - 持っていない人には当たらない
   - フルチャージ弾は当たっても消えずに貫通する

## 作りのポイント

- 効果音は音声ファイルを使わず、Web Audio でその場で合成する（`src/sound.ts`）。AudioContext はページに1つだけ作って使い回す。ほかの人の音は距離で小さくする
- `onUseStart` でため始めの時刻を覚え、`onUseEnd` でためた秒数から弾を決めて撃つ（`src/Item.tsx`）
- `onUseStart` / `onUseEnd` は持っている本人の画面でだけ呼ばれる。ためている様子と弾は `useInstanceEvent` でほかの人に送る。送った本人には届かないので、自分の画面には直接出す
- 当たり判定は撃たれた側が自分の画面で行う（`src/battle.ts`）。弾は全員の画面で同じように飛んでいるので、`useUsers().getLocalMovement()` の足元から頭までのカプセルに重なったら、`useInstanceEvent` で「当たった」を全員に知らせる。参戦中かどうかは `onGrab` / `onRelease` の `isMine` で決める
- HP は撃たれた本人が持つ（持ち替えても引き継ぐ）。持っている間は、HP が変わるたびに持ち主がそのバスターのランプの値を全員に知らせる
- 弾の向きは `onUseEnd` の `transform`（アイテムのローカル座標）の -Z。弾もアイテムの中に描くので、座標を変換しなくてよい
- 持っている間は `children` そのものが持ち主の手元に動く（0.64.0 で `renderGhost` は廃止）。操作説明は `onGrab` / `onRelease`（全員の画面で呼ばれる）で持っている間だけ外す

## 開発

```bash
npm install
npm run dev
```

`DevEnvironment` で XRift と同じ操作で試せます（クリックでマウスを固定 → G で持つ → クリックでためて撃つ）。

```bash
npm run build
```
